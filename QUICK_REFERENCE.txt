⚙️ SETUP COMMANDS (via REPL)
─────────────────────────────────────────────────────────────────────
# Set RTC time
from machine import I2C, Pin
from ds3231 import DS3231
i2c = I2C(0, scl=Pin(22), sda=Pin(21))
rtc = DS3231(i2c)
rtc.set_time(2026, 3, 18, 3, 7, 30, 0)  # year,mon,day,wday,hr,min,sec

# Set alarm time
import main
main.alarm_clock.alarm_hour = 7
main.alarm_clock.alarm_minute = 30
main.alarm_clock.alarm_enabled = True
main.alarm_clock.save_settings()

🎮 CONTROLS
─────────────────────────────────────────────────────────────────────
Rotary encoder:
  - Rotate        Navigate menu items
  - Click         Select/confirm current menu item

Touch sensors:
  - Touch GPIO4   Snooze alarm (5 minutes)
  - Touch GPIO0   Stop alarm completely

🔧 TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────
Problem              Solution
─────────────────────────────────────────────────────────────────────
Display blank        Check CLK/DIO wiring, run test_display.py
RTC not found        Verify I2C: i2c.scan() should show [104]
No sound             Check SD card FAT32, file names, connections
Touch not working    Run test_touch.py, adjust thresholds
LEDs not lighting    Check 5V power!, run test_leds.py
Can't upload files   Press RESET, check USB cable, drivers
