⚙️ SETUP COMMANDS
─────────────────────────────────────────────────────────────────────
Most settings can now be changed via the on-device menu!

If you need REPL access (rare):

# Set RTC time (only needed on first boot)
from machine import I2C, Pin
from ds3231 import DS3231
i2c = I2C(0, scl=Pin(22), sda=Pin(21))
rtc = DS3231(i2c)
rtc.set_time(2026, 3, 18, 3, 7, 30, 0)  # year,mon,day,wday,hr,min,sec

🌅 ALARM & NIGHT LIGHT BEHAVIOR
─────────────────────────────────────────────────────────────────────
Alarm:
  Duration:         10 minutes (600s)
  Snooze:           5 minutes (300s), resumes from same point
  Max duration:     30 minutes auto-stop
  
  LED Sunrise Timeline (if LED enabled):
    0:00 - 2:30     Dark red → red
    2:30 - 5:00     Red → orange
    5:00 - 7:30     Orange → yellow
    7:30 - 10:00    Yellow → white
  
  Sound Volume Timeline:
    0:00            Volume = vol_start (per-track setting, default 5)
    10:00           Volume = DFPLAYER_VOLUME_MAX (25)

Night Light:
  Trigger:          Touch snooze (GPIO4) when alarm inactive AND dark
  Duration:         30 seconds full white
  Fade:             10 seconds to off
  Threshold:        EMA < 80 (adjustable in config.py)

MP3 Sound Tracks:
  0001.mp3          BIRD  (Birds - default)
  0002.mp3          SIRN  (Siren)
  0003.mp3          COCK  (Cockerel)
  0004.mp3          BELL  (Bell)
  0005.mp3          BRD2  (Bird 2)
  0006.mp3          POP   (Pop music)

🎮 CONTROLS
─────────────────────────────────────────────────────────────────────
Rotary Encoder:
  - Rotate              Navigate menu when alarm off
  - Click               Select/confirm menu item when alarm off
                        STOP ALARM when alarm active
  
  When Alarm Active:
    - Rotation:         Ignored
    - Click:            Stop alarm immediately ⚠️ NEW!

Touch Sensors:
  - GPIO4 (Snooze)      Snooze 5 min (pauses & resumes from same point)
                        OR trigger night light (if dark & alarm off)
  - GPIO0 (Stop):       Deprecated - use encoder button instead

🔧 TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────
Problem                  Solution
─────────────────────────────────────────────────────────────────────
Display stuck on INIT     Unplug+replug USB (power cycle) - I2C bus stuck
Display shows 00:00       RTC not found or not set - use CLOC menu
RTC not found            Verify I2C: i2c.scan() should show [104]
No sound                 Check SD card FAT32, file names 0001-0006.mp3
Touch not working        GPIO4 tested and works; GPIO0 unreliable
Night light not on       Room too bright - cover sensor or lower threshold
LEDs not lighting        Check 5V power supply to WS2812B
Alarm won't stop         Use encoder button click (GPIO0 is unreliable)

💾 SD CARD SETUP
─────────────────────────────────────────────────────────────────────
Format:   FAT32
Structure:
  /mp3/0001.mp3   (Birds - default alarm)
  /mp3/0002.mp3   (Siren)
  /mp3/0003.mp3   (Cockerel)
  /mp3/0004.mp3   (Bell)
  /mp3/0005.mp3   (Bird 2)
  /mp3/0006.mp3   (Pop)

Requirements:
  - Exact naming: 0001.mp3, 0002.mp3, etc. (not 1.mp3 or 001.mp3!)
  - Sample rate: 8-48kHz
  - Format: MP3 (bitrate 128-320 kbps recommended)
