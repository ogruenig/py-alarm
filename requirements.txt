# All dependencies are built-in to MicroPython for ESP32

# Target hardware: ESP32 (tested on ESP32 D1 Mini)

# Built-in modules used:
# - machine (Pin, I2C, UART, TouchPad, ADC)
# - neopixel (WS2812B LED control)
# - time
# - json
